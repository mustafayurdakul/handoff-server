# Add date sorting to the document list

## Description

Users have to scan the whole list to find the newest documents. The list should be sortable by date.

## Acceptance criteria

- Above the list there is a sort control with the options "Newest" and "Oldest".
- The default order is "Newest".
- Sorting works together with the title search.
- The behavior is covered by tests.
